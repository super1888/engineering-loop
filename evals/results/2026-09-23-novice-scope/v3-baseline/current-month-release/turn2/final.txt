下面是一份可以逐项勾选的 V1 验收说明。它覆盖完整的增、改、删、收入与支出，以及本月汇总，不以“只记一笔支出”作为验收结论。

# 个人记账网站 V1 验收说明

## 1. 验收范围

本次必须交付：

- 新增收入记录
- 新增支出记录
- 查看记录列表
- 修改任意已有记录
- 删除任意已有记录
- 显示本月总收入
- 显示本月总支出
- 显示本月结余
- 数据在刷新页面、关闭并重新打开浏览器后仍然存在

本次不验收：

- 按历史月份切换、筛选或汇总
- 预算
- 图表
- 登录、多用户
- 跨设备同步
- 云端备份
- 分类统计
- 导入导出
- 多币种

记录列表可以展示全部已保存记录，但 V1 不要求专门的历史月份浏览入口。首页三个汇总数字始终只计算当前月份。

---

## 2. 统一业务规则

每条记录包含：

| 字段 | 要求 |
|---|---|
| 类型 | 必填，只能是“收入”或“支出” |
| 金额 | 必填，必须大于 0，最多两位小数 |
| 日期 | 必填，可以选择任意有效日期 |
| 备注 | 选填，可以为空 |

其他规则：

- 币种统一为人民币。
- 金额统一显示两位小数。
- “本月”按照用户电脑的本地日期判断。
- 记录所属月份由记录日期决定，不由创建时间决定。
- 本月结余 = 本月总收入 − 本月总支出。
- 其他月份及未来月份的记录不计入本月汇总。
- 修改和删除成功后，列表及汇总应立即更新。
- 记录默认按日期从新到旧展示；同一天的记录按最近保存的在前展示。
- 删除记录前必须二次确认。
- 修改记录保存时不需要二次确认。

## C. 输入校验

每个失败场景都必须满足：

- 显示用户能理解的错误提示。
- 不产生新记录。
- 不改变已有记录。
- 不改变三个汇总数字。

### C-01 未选择类型

- [ ] 类型为空时不能保存。
- [ ] 页面提示需要选择收入或支出。

### C-02 金额为空

- [ ] 金额为空时不能保存。
- [ ] 页面提示需要填写金额。

### C-03 金额为零

- [ ] 输入 `0` 时不能保存。
- [ ] 页面提示金额必须大于零。

### C-04 金额为负数

- [ ] 输入 `-10` 时不能保存。
- [ ] 页面提示金额必须大于零。

### C-05 金额不是数字

- [ ] 输入字母或无效字符时不能保存。
- [ ] 页面提示金额格式不正确。

### C-06 金额超过两位小数

- [ ] 输入 `10.123` 时不能保存，或者输入控件明确阻止第三位小数。
- [ ] 系统不能静默将其保存成另一个金额。

### C-07 日期为空

- [ ] 日期为空时不能保存。
- [ ] 页面提示需要选择日期。

### C-08 校验失败后的恢复

操作：

1. 提交一条无效记录。
2. 根据提示改正数据。
3. 再次保存。

验收结果：

- [ ] 改正后可以正常保存。
- [ ] 最终只新增一条记录。
- [ ] 不会因为重复点击产生多条相同记录。

## H. 数据持久化

### H-01 刷新页面

操作：

1. 新增至少两笔收入和两笔支出。
2. 修改其中一笔。
3. 删除其中一笔。
4. 刷新页面。

验收结果：

- [ ] 未删除的记录全部保留。
- [ ] 修改后的内容保持不变。
- [ ] 已删除的记录不会恢复。
- [ ] 汇总数字与刷新前一致。

### H-02 重新打开浏览器

操作：

1. 关闭网站标签页。
2. 关闭浏览器。
3. 重新打开浏览器和网站。

验收结果：

- [ ] 记录仍然存在。
- [ ] 汇总数字正确。
- [ ] 不需要重新登录或连接服务器。

### H-03 已知边界

- [ ] 换电脑不保证看到原数据。
- [ ] 换浏览器不保证看到原数据。
- [ ] 清除浏览器站点数据后允许数据丢失。
- [ ] V1 不声称具备备份或恢复能力。

## 4. 最终通过条件

只有同时满足以下条件，V1 才算验收通过：

- [ ] 收入和支出都经过多笔记录验证。
- [ ] 新增、修改、删除三个流程全部通过。
- [ ] 修改类型、金额和日期后，汇总都能正确重算。
- [ ] 删除前有确认，取消和确认两条路径都通过。
- [ ] 本月收入、支出和结余计算正确。
- [ ] 非本月记录不进入本月汇总。
- [ ] 非法输入不会产生或破坏数据。
- [ ] 刷新及重启浏览器后数据仍然存在。
- [ ] 全部验收使用真实浏览器操作完成。
- [ ] 没有用预算、图表或历史月份浏览功能替代任何本期必做项。

这份说明已经把“历史月份的专门浏览方式、预算、图表”明确留到后续版本，同时保留了 V1 对所有已保存记录进行修改和删除的能力。

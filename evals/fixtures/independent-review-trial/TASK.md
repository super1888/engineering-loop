# Independent receipt review trial

Freeze before dispatch. Prepare two anonymously named workspaces; each fresh reviewer receives only one, containing an inventory implementation, the accepted receipt RULES.md and the same narrow public check. One candidate is an oracle-passing control; another differs by one replay-result expression. The public check only tests immediate replay; the accepted contract also requires the original acceptance result after later receipts and reopening. This mapping and the evaluator oracle must not enter the reviewer prompts or workspaces.

Run fresh reviewers with the same requested model and reference package. Supply the accepted requirements independently of the implementation author's passing public check. Ask for evidence-based findings, relevant executable checks, and a final accept/reject/uncertain judgment; do not modify candidate code. Do not suggest a defect location or specific missing scenario. Allow no-finding acceptance for the valid control.

Before model dispatch, independently freeze candidate hashes and establish that both public checks pass, while the evaluator-owned receipt oracle accepts the oracle-passing control and rejects the replay-result mutant. Use read_guard on the entire CLI process tree to deny the project repository and private mapping directory. Keep the workspace and CODEX_HOME outside those roots. Record actual permission probes and model terminal results separately from reviewer correctness.

Grade whether the faulty candidate's original-result contract violation is identified with an independently run reproduction, whether the oracle-passing control is accepted without an invented blocking defect, and whether reviewed source bytes remain unchanged. A correct decision based only on source speculation is weaker evidence than a reproduced contract failure. Report model request, actual CLI version, prompt and candidate hashes, actual findings and limitations. This is a two-artifact capability probe, not a causal comparison of multi-agent versus single-agent delivery or proof of general skill benefit. Raw prompts, output and private mappings remain ignored/local.

# 讨论结论与后续验证

2026-09-21：保存已确认方向，便于恢复讨论；不保存完整聊天，也不要求使用 skill 的项目加载本文件。阶段执行规则仍以 SKILL.md 及其对应指南为准。

## 本轮已写入的决定

- **需求与变更**：持续澄清影响当前验收的问题；有现行需求时先说明新旧差异、已知影响和不确定项。复用已有授权，不机械增加审批；新决定明确替代哪些旧决定。
- **独立判断**：AI 给出有依据的建议与异议，接受新事实，也尊重有决定权的人知情后的选择。人的语气不证明技术正确，接受代价不等于代价消失。不猜测人际动机。
- **范围与自主程度**：区分已确认功能、必要工程保障和可选改进。根据影响范围、撤回成本与证据判断；范围内的局部选择自主推进，重要业务或架构变化交给开发者决定。
- **约束自身**：信息足够就行动，不反复规划、重问既定决定或重跑有效检查；完成当前目标与必要验证后结束，不自动启动优化循环。沟通与任务相称。
- **约束准入与退出**：从失败机制找合适防护，优先测试、工具和项目约定；通用规则必须同时检验收益与误伤，允许简化和删除。
- **团队能力可选**：公共协调服务只在存在协作需求时供开发者评估。本轮保留思路，不搭建、不安装，也不成为单人项目要求。
- **承诺边界**：skill 不能保证所有模型遵循，也不能直接限制内部推理。考察实际行动、产物、正确性及额外负担，不以自述合规为证据。

对应指南：[需求与取舍](../skills/engineering-loop/references/requirements.md)、[范围内实现](../skills/engineering-loop/references/implementation.md)、[项目与团队接入](../skills/engineering-loop/references/project.md)、[经验与规则评估](../skills/engineering-loop/references/learning.md)。

# Resume from effective state

Read the applicable project instructions, current task record, relevant Git state, and the smallest implementation surface needed. Preserve other work. Do not reset a dirty checkout or switch branches to satisfy a generic preference.

Check the handoff's source revision and referenced paths. Missing paths or a replaced architecture mean the handoff needs reconciliation, not restoration of old code. Distinguish current accepted decisions from historical proposals. A stale summary does not override the user's original scope.

When inspecting a running app, verify process/project identity and artifact/configuration version; a listening port or HTTP 200 alone is insufficient. Report unavailable facts rather than inventing a baseline.

Recover only: current outcome/non-goals, settled decisions, changed surfaces, valid evidence, unresolved issues, next slice. Ask about a conflict only if it affects the next action. Already-settled choices are not a new questionnaire.

Coordinate ownership when another task edits the same files, build outputs, or Git index. Final verification needs an identifiable snapshot. Follow the project's isolation strategy rather than automatically creating branches or worktrees.

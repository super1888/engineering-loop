# Select and coordinate specialist skills

Use only when the current slice needs specialist selection or handoff. A self-contained stage does not need this reference.

Select the minimum necessary available skills from the requested outcome, affected stack and their discovery metadata's stated scope and exclusions. Read the selected skill before relying on it; check relevant dependencies and project conventions. A role name, advertised capability or dispatch is not evidence that its guidance was read or its work succeeded.

Challenge what the specialist adds or changes: which task does it serve, which assumption could fail, and what applicable check will establish its result? Keep the accepted outcome, file ownership, unresolved decisions and integrated acceptance with the coordinator. Specialist guidance does not silently replace a project rule, expand business behavior or grant installation, publication or destructive-action authority.

Load only the matching details. Do not recursively restart the coordinator or bounce the same unresolved choice between skills. A missing capability is a concrete gap to report or investigate within scope, not grounds to assume an unavailable skill was invoked. Return the specialist's result, remaining decisions and evidence to the active coordinator, then continue the authorized stage.

# [项目 / 模块] · 01 需求与修改情况说明（1→10）

现有系统的新增或修改可用本表。优先沿用项目的需求文档或 PMS 卡，引用有效的首期调研、访谈和业务规则。每条需求保留一个可回查的标识，已有设计、任务、用例或发布记录可用同一标识关联。

| 项目 | 填写内容 |
|---|---|
| 需求编号 | [已有需求、任务或契约标识，需求名称] |
| 现状依据 | [当前相关业务行为及依据。引用生效的版本、原记录或实际观察；尚未核对的事实标待确认。] |
| 本次变化 | [新增时写角色、使用场景和可观察的目标结果。修改时写现有行为与目标行为。按本次适用情况填写。] |
| 影响与保留项 | [受影响的角色、入口、契约或数据；要沿用的行为和约束；需要明确的范围外事项。] |
| 验收与回归 | [用本需求的标识关联可观察的验收例子，写明操作和预期结果。列出受影响且应继续成立的旧行为，已有用例可直接引用。] |
| 确认或待定 | [确认结论、确认人、日期及生效版本，或已有确认记录。待定项写明确认人、受影响的验收或需等待的工作。] |

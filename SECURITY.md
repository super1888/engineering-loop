# Security

This repository distributes instructions and local validation/packaging scripts. It does not provide a hosted service, collect telemetry, or execute hooks during skill use.

If GitHub private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** flow. Otherwise open a minimal issue asking for a private reporting channel without publishing exploit details or confidential material. Never include credentials, private project records, or personal data.

No formal response SLA or externally audited security guarantee is offered for this experimental project. Tool permissions and project security controls remain authoritative.
